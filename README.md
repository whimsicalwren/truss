# Truss

Truss is a minecraft mod meant to bridge minecraft servers to discord servers.

## Current Features

- none lol

## Planned Features

- Bridge chat messages between minecraft and discord
- Use commands in minecraft from discord
- Mention discord users from minecraft (maybe replying as well?)
- Send emojis from minecraft, and display them in minecraft as well
    - possibly including server emojis
- stickers (see above)
- gifs and images send in discord will show their content in minecraft when hovered with mouse
- edit and delete messages on both sides
- mention minecraft users (play a sound effect and highlight the message)
